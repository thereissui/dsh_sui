## 各插件的作用（速查）

| 插件 | 干什么 |
|---|---|
| `surfcore` | QQ × B站 桥接主体：配置、记忆、人格分层、安全隔离、桌面宠物 |
| `dsh-bilibili` | 读 B站视频：字幕/转写、弹幕、评论、关键帧 |
| `dsh-memewiki` | 梗百科，6792 条词库，自动查梗并注入 |
| `dsh-free-search` | 39 个搜索引擎的聚合（多数免 key） |
| `cc-safety-net` | 拦截危险 shell 命令（`git restore`、`rm -rf` 这类） |
| `dsh-global-rules` | 全局规则注入（每条都进系统提示） |
| `dsh-ops` | 运维工具：bash 执行、文件检查等 |
| `modlens` | 给纯文本模型看图的能力 |
