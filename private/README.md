# private/ —— 这个目录永远不进 git

放这里的东西：**只在本机用、绝对不能被推送到公网**的内容。

`.gitignore` 里 `/private/` 是整目录挡掉的，所以：

- `git add -A` 不会带上这里
- `git status` 里看不到这里的东西
- `git push` 永远推不上去

## 该放什么

| 类型 | 例子 |
|---|---|
| 人格卡正文 | 角色的内外设定、语气表、ban 表 |
| 身份信息 | QQ 号、B站 mid、群号 |
| 凭据 | GitHub token、SESSDATA、API key |
| 本机路径 | 含用户名的绝对路径 |
| 私人对话摘录 | 聊天记录、日记 |

## 该去哪

- **人格卡**：真正生效的那份在 `.dsh/surfcore/characters/char-*/`，那里本来就不在 git 里。
  这里是**备份/草稿**，方便跨机器带。
- **凭据**：不建议放任何文件，用系统的凭据管理器（`wincred`）更安全。
  真要放，加密后再放。

## 换机器时

```bash
# 从旧机拷出去（不走 git）
# 新机拉仓库后，把 private/ 手动放回来
```

这样公开仓库里永远只有能见人的部分。
